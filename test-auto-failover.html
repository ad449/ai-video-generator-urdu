⚡ How Auto-Failover Works

  1. User selects "Auto" mode in dropdown
  2. System checks which API keys are configured
  3. Sorts available providers by priority (free first)
  4. Tries providers sequentially until success
  5. Tracks success/failure rates for optimization
  6. Falls back to paid options if free ones fail
