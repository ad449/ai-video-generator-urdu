OPTION 2: GITHUB PAGES (RECOMMENDED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Steps:
1. Create GitHub repository
2. Push all files to main branch
3. Go to Settings → Pages
4. Select: Deploy from main branch
5. Wait ~2 minutes
6. Access via: username.github.io/repo-name

Commands:
  git init
  git add .
  git commit -m "Initial commit"
  git remote add origin https://github.com/username/repo-name.git
  git push -u origin main

Pros: Free, easy, reliable
Cons: Public repository


OPTION 3: NETLIFY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Steps:
1. Go to netlify.com
2. Drag & drop project folder
3. Done! Get instant URL

OR with CLI:
  npm install -g netlify-cli
  netlify deploy --prod

Pros: Drag & drop, instant deploy
Cons: Requires Netlify account


OPTION 4: VERCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Steps:
1. Go to vercel.com
2. Import Git repository
3. Deploy automatically

OR with CLI:
  npm install -g vercel
  vercel

Pros: Auto-deploy on git push
Cons: Requires Vercel account


OPTION 5: CLOUDFLARE PAGES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Steps:
1. Go to pages.cloudflare.com
2. Connect Git repository
3. Deploy

Pros: Fast CDN, free SSL
Cons: Requires CloudFlare account


OPTION 6: AWS S3 + CLOUDFRONT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Steps:

2. Enable static website hosting
3. Upload all files
4. Set public read permissions
5. (Optional) Add CloudFront CDN

Pros: Scalable, enterprise-grade
Cons: More complex setup
