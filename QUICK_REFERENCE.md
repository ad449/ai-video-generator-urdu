## ⚡ Pro Tips

### Save Credits:
- Use 3 scenes for testing
- Batch generate stories first
- Switch to "Manual" when out of credits

### Quality:
- FAL.ai: Fast + Good (768x512)
- Replicate: Various options
- Manual (Google Flow): Best (up to 4K)

### Speed:
- FAL.ai: ~30 sec/video ⚡
- Replicate: ~60-90 sec/video
- Manual: ~45 sec/video (manual work)

---

## 🔧 Troubleshooting

### Video Failed?
```
→ Click "Retry Generation"
→ Check API key validity
→ Switch to different provider
```

### Out of Credits?
```
→ Use "Manual" mode
→ Copy prompts
→ Use Google Flow (50 free daily)
```

### Story Not Good?
```
→ Be more specific in input
→ Add details: time, place, characters
→ Try different story type
```
