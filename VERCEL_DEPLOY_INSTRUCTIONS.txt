🚀 QUICK VERCEL DEPLOYMENT GUIDE
================================

✅ Code pushed to GitHub: https://github.com/ad449/ai-video-generator-urdu

📦 DEPLOYMENT STEPS:

1. Go to Vercel Dashboard:
   👉 https://vercel.com/new

2. Import GitHub Repository:
   - Click "Import Project"
   - Select: ad449/ai-video-generator-urdu
   - Click "Import"

3. Configure Project:
   - Framework Preset: Other
   - Root Directory: ./
   - Build Command: (leave empty)
   - Output Directory: (leave empty)
   
4. Add Environment Variables (IMPORTANT!):
   
   Variable Name: GROQ_API_KEY
   Value: Set this in Vercel using your own Groq API key. Do not commit it.
   
   Variable Name: HUGGINGFACE_TOKEN
   Value: Set this in Vercel using your own Hugging Face token. Do not commit it.

5. Click "Deploy"

6. Wait 1-2 minutes for deployment to complete

7. Your app will be live at:
   https://ai-video-generator-urdu.vercel.app
   (or similar URL)

🆘 TROUBLESHOOTING:

If deployment fails:
- Check environment variables are set correctly
- View deployment logs in Vercel

If app doesn't work:
- Check browser console for errors
- Verify API keys in Vercel environment variables
- Test API endpoints: /api/config, /api/groq
